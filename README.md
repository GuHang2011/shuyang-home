面向在外沭阳老乡的生活社区，将会员服务、活动报名、论坛聊天、便民互助和运营管理放在一起。提供 **电脑网页、手机 H5 与微信小程序源码**，正式部署共用后端 API。

基于 **Vue 3 · TypeScript · Element Plus · uni-app · Spring Boot**。当前为可本地运行的单实例试点版本；GitHub Pages 提供无需安装的独立体验版。

## 在线体验

**体验地址：[guhang2011.github.io/shuyang-home](https://guhang2011.github.io/shuyang-home/)**

1. 打开页面，默认以演示会员身份进入；电脑和手机均可访问。
2. 用顶部“体验身份”切换会员、管理员或游客，按下表体验主要流程。
3. 点击“重置数据”可恢复初始样例；“体验指引”提供操作说明。

| 体验身份 | 建议从这里开始 |
| --- | --- |
| 演示会员 | 首页搜索活动 → 报名；会员中心 → 出示二维码；论坛、聊天、相册与换肤 |

| 游客 | 浏览首页、活动、社区内容和家乡专题，了解平台入口 |

如需使用登录表单，演示账号为 `demo`／`admin`，演示密码均为 `Demo12345678`。这些账号只属于独立体验版，正式部署需自行设置管理员密码。

> [!NOTE]
> 演示资料与附件只保存在当前浏览器，不同访客之间不共享，不产生真实消息、交易或收款。AI 使用明确标注的固定示例，真实模型需在后端配置 OpenAI 兼容服务。文件报表、完整生活服务及定位签到请在完整部署版本中验收。

## 快速启动

环境：Node.js 18+、npm、JDK 8 与 Maven wrapper。首次安装需要访问 npm / Maven 仓库。

在项目根目录分别打开两个 PowerShell 终端：

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-Backend.ps1 -Build
powershell -ExecutionPolicy Bypass -File .\Start-Frontend.ps1
```

访问 `http://127.0.0.1:8888`，后端默认端口 `9999`。首次启动交互设置超级管理员 `admin` 的初始密码，首次登录强制改密；无内置通用管理员密码。默认数据库为 `backend/data/shuyang-home.mv.db`。

手机 H5 / 微信小程序：

```powershell
cd frontend
npm ci
cd mobile
npm ci
npm run dev:h5
# 构建发布产物
npm run build:h5
npm run build:mp-weixin
```

微信开发者工具导入 `mobile/dist/build/mp-weixin`。正式使用前填写真实 AppID、HTTPS API 地址，配置 request / uploadFile / downloadFile 合法域名与隐私声明。手机相机和定位需要 HTTPS 或本机 localhost 安全上下文。详见[启动与部署](docs/启动与部署.md)。

## 代码结构

| 目录 | 职责 |
| --- | --- |
| `backend` | Java / Spring Boot / JDBC / H2 后端及集成测试 |
| `frontend/src` | Vue 3 响应式网页、运营工作台 |
| `frontend/mobile` | uni-app H5 与微信小程序 |
| `frontend/shared` | 多端业务逻辑、权限状态、天气、扫码与文案 |
| `deploy` | Nginx、systemd 与环境变量模板 |
| `docs` | 需求、部署、问题修复、验收和截图 |
| `scripts` | 启动、隔离测试、构建打包与发布校验 |

从 v1.2.1 起，前端统一放在 `frontend`，后端统一放在 `backend`；启动、测试和打包入口已同步更新。已有本地安装的路径迁移见[目录迁移说明](docs/目录迁移说明.md)。学生数据未迁移，旧源码、数据库、缓存、日志、依赖目录和本地打包产物不上传仓库。

## 当前边界与素材

- 仍使用 Java 8 / Spring Boot 2.3 和单实例 H2；公网正式运营前需升级受维护依赖、完成容量、备份与部署验收。
- 聊天为定时刷新，无 WebSocket、音视频或离线推送；手机号账号由人工审核，没有短信认证、微信一键登录或支付。
- 小程序真实 AppID、微信平台配置、手机摄像头／键盘／前后台切换和真机定位验收仍待完成。
- 用户提供的 Alltuu 活动相册访问返回 403，原照片未导入。目前提供原相册入口和本地上传功能。验收条纹图仅用于测试。
- JSON 业务记录支持可选 AES 加密；附件存于数据库 BLOB，未由该字段加密机制覆盖，需通过主机与备份存储措施保护。
