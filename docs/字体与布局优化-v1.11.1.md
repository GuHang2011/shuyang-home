# 字体与布局优化 · v1.11.1

日期：2026-11-11。此次围绕首页和“一凡说高铁”调整阅读与操作体验，兼顾Web、手机H5及微信小程序。

## 改了什么

字体统一为本机中文无衬线字体，依次适配苹果、Windows和安卓，不依赖远程字体下载。正文通常16px，论坛列表摘要15–16px，按钮15px，辅助信息14px；标题主要使用600字重。修正历史样式重复覆盖字号、控件字体继承不一致的问题。

温暖主题保留米白底色、深蓝操作和暖金点缀，正文改为蓝灰，减少整页棕色文字。商务与深色主题继续可用。

论坛页面减少重复标题与说明。发帖按钮放在讨论标题右侧，分类在手机容器内横向滑动；搜索框与排序在同一行，H5使用原生选择器。列表只保留有用标签，固定专题不重复显示“淮新高铁”，公开帖不再每条标注“已通过”；个人发布仍展示审核状态。帖子摘要最多两行，进入详情可读全文。

移动端将返回首页和换肤合为一栏。首页会员卡收紧空白，保留事项、电子会员卡、通知及统计；修复深色H5静态服务图标、天气入口颜色。资讯、资料、来源、照片、语音、审核和版主功能沿用现有业务逻辑。

论坛搜索框使用16px，避免iOS对小字号输入框聚焦时自动缩放。手机版在管理确认表单中隐藏发帖入口，取消确认后回到原列表。
