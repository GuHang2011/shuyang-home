# 二期扩展：影像、签到、论坛治理与家乡特产

用户已确认：扫描先实现二维码；家乡特产采用在线下单、人工确认与线下结算。广告不接支付、众筹不在线收款的约定继续有效。

本轮实施范围：

- 活动相册：分组封面、图片墙、预览、图片上传和发布管理，保留提供的外部相册来源。当前外部相册返回403，无法导入照片，不用其他图片冒充活动素材。
- 移动地点签到：组织者设置活动签到点、半径、时间；会员报名后主动授权位置签到，二维码作为活动入口，不把扫码本身等同于签到成功。服务时长仍由组织者核定。
- 拍照与扫描：手机拍照/相册选图、手机和电脑二维码扫描、选图识码；识别结果先确认，仅已知站内二维码触发导航，不自动访问陌生网址。
- 聊天附件：图片和常用文件，权限随会话成员及撤回状态校验，文件大小/类型限制，下载权限不因知道链接而绕过。
- 管理员：超级管理员维护管理员角色，普通管理员管理运营与普通会员；版主限定指定论坛板块，不能操作会员账号或其他板块。
- 论坛：恢复默认入口，楼层编号、引用回复、转发来源、删帖、隐藏/恢复、板块禁言/移出/恢复、个人拉黑；转发原帖隐藏后不继续公开原文。
- 家乡特产：分类和图文详情、库存、在线订单、人工确认、线下结算、发货/自提、取消与库存退回；订单收货信息仅买家和管理员可见，不提供虚假的支付成功状态。

实现、测试及发布包状态以最终验收记录为准。本清单不是完工声明。
