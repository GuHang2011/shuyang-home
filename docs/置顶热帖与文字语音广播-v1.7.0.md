# 置顶、热帖与文字语音广播 · v1.7.0

## 使用方式

- 网页：管理工作台 → 内容与活动 → 论坛管理／全站广播。
- 手机 H5／小程序：我的 → 全站广播；我的论坛话题 → 版主管理，或进入公开话题详情操作。
- 所有访问者（含未登录访客）可阅读有效广播，点击“收听广播”后主动加载、播放语音。支持多条切换和本次关闭；刷新页面或广播更新版本后可重新显示。

## 置顶和热帖

管理员、组织者及有该板块权限的版主可以置顶、取消置顶、设为热帖、取消热帖。每个板块最多置顶 3 条已审核公开话题；普通会员、其他板块版主不能操作。隐藏或删除后清除推荐，恢复公开后需要重新推荐。

全部话题置顶优先，置顶间按置顶时间排列，普通话题按发布时间排列。“热帖”是管理人员推荐的独立筛选，置顶优先，其余按已审核回复数、发布时间排列；支持板块和关键词筛选。推荐不会绕过审核、拉黑或移出版块的可见性限制。

## 广播规则

只有超级管理员、管理员可以管理广播、上传广播语音。文字必填：标题 2–60 字、正文 2–1000 字；音频可选，支持 MP3／M4A／WAV，最多 10 MB，服务端同时检查文件格式。

表单使用北京时间。生效时间留空立即生效，到期时间必填且晚于生效时间和当前时间。支持草稿、立即发布、预约发布、编辑和撤下；公开接口仅返回当前有效版本。已发布内容也可以保存为草稿，停止公开展示。

| 状态 | 公开展示与语音访问 |
| --- | --- |
| 草稿 | 不公开；管理员可试听当前语音 |
| 待生效 | 开始时间之前不公开 |
| 广播中 | 开始时刻包含、到期时刻不包含；访客可查看并收听 |
| 已到期／已撤下 | 不公开；公众直接访问音频也返回不可用 |

前台约每 30 秒获取最新广播，返回页面时立即刷新；使用服务器时间偏移校正设备时间，已加载广播到期后在本地移除。网络失败时清除旧广播并显示重试入口，后台暂停轮询。撤下在其他在线页面通常于下次轮询生效；已下载的音频无法从用户设备收回。

新建使用固定请求编号防止网络重试重复创建；同编号不同内容会拒绝，提示从列表编辑原广播。编辑、撤下和帖子推荐携带版本号，冲突返回 409，不覆盖他人更新。失败保留输入与音频供重试，退出账号、切换身份、组件卸载时丢弃迟到响应。

## 接口与数据

| 接口 | 用途 |
| --- | --- |
| `PUT /forum/topics/{id}/promotion` | `revision` 加可选布尔字段 `pinned`／`hot`，仅修改给定字段 |
| `GET /broadcasts` | `serverTime` 和当前有效广播 `items` |
| `GET /admin/broadcasts` | 管理列表及计算后的状态 |
| `POST /admin/broadcasts` | 带 UUID `requestId` 创建，支持相同请求重放 |
| `PUT /admin/broadcasts/{id}` | 带 `revision` 完整更新 |
| `POST /admin/broadcasts/{id}/withdraw` | 带 `revision` 撤下 |
| `POST /media/upload` | `scope=broadcast` 上传管理员自己的语音 |

广播沿用现有记录存储，音频沿用附件存储，不新增依赖或破坏已有数据结构。公共响应使用显式字段投影，不暴露创建者、原始幂等请求。语音只能绑定本人为广播上传且未使用的附件；替换后旧附件无法通过原地址访问。管理操作记录审计日志。

## 本轮处理的问题

| 问题 | 解决方式 |
| --- | --- |
| 推荐越权或绕过审核 | 服务端沿用板块权限和公开状态校验，公共查询保持原可见性过滤 |
| 无限置顶挤占普通话题 | 每板块最多 3 条，管理页说明限制 |
| 隐藏后恢复意外重新推荐 | 隐藏、删除时清除标记并递增版本 |
| 热帖空列表仍提示“发起第一个话题” | 改为当前筛选无热帖，提示切换板块或查看全部 |
| 多人编辑覆盖、重复创建 | 版本冲突校验、稳定请求编号、前端提交锁 |
| 切换身份后显示旧草稿或迟到响应 | 请求作用域失效及私有状态清理 |
| 草稿、撤下、替换音频被直接下载 | 下载时校验广播状态和当前附件引用 |
| 关闭后看不到修订 | 按广播 ID 和版本记录本次关闭，新版本重新展示 |
| 重放请求成功提示与实际状态不符 | 以服务端返回状态展示保存结果 |
| H5 不支持音频解码时产生未处理异常 | 直接处理浏览器播放 Promise，保留错误提示；小程序沿用原生音频上下文 |
| 手机切到后台后迟到下载仍开始播放 | 后台切换时使未完成播放请求失效，并释放迟到音频资源 |
