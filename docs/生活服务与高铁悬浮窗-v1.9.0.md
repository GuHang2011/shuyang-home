# 生活服务与高铁庆祝悬浮窗

版本：1.9.0。2026-11-03 开发，2026-11-05 随大屏、通讯录合并发布。GitHub Pages 仅演示指南与私人清单，完整流程需运行后端。

## 使用入口

电脑、手机网页及小程序首页增加“生活服务”。个人中心和统一“我的事项”也可进入，工作台中选择生活服务事项可直达对应详情。服务通知与业务通知共用收件人和已读状态。

| 功能 | 本版可用流程 |
| --- | --- |
| 办事指南 | 地区和关键词筛选、官方来源链接、核验日期、私人材料清单、信息纠错；超过90天未核验提示更新 |
| 老乡帮办 | 发布审核、申请帮忙、选择一位负责人、提交结果、求助者确认解决、退出申请与管理员协调 |
| 求职招聘 | 用工单位、身份、薪资计薪方式、工作时间、用工类型、截止日期；表达意向、发布者回应、暂停和结束招聘 |
| 便民服务 | 自愿公开服务名片、服务范围与费用说明、可联系时段、图片、咨询申请和私聊入口 |
| 活动出行 | 关联真实活动、集合点选择和人数、公交停车说明、日历文件、签到入口、活动地点和日期的天气 |
| 特产到货 | 关联真实商品、预计到货、站内订阅、补库存提醒、下单入口 |
| 预约自提 | 选择已确认订单和容量受限时段、改约与取消、本人或代领二维码、管理员核对后交付、代领撤销 |
| 共建公示 | 项目进度、计划日期、延期与结项说明、实际认领与核实交付数量 |
| 失物招领 | 寻物／招领发布、照片、日期地点、私密认领说明、接受和登记交接 |

普通会员内容需审核，编辑后重新进入审核。指南和出行卡由组织者或管理员维护；到货和自提时段由管理员维护。管理员不能替求助者确认“已解决”。服务名片随会员名录公开偏好生效；照片随所属内容和审核权限控制。

发布表单支持最多6张照片、上传重试、按账号保存文字草稿。草稿不保留上传照片，恢复时需重新选择。生活服务支持大字模式与至少44px的主要触控按钮。

## 高铁庆祝悬浮窗

首页展示“庆祝淮新高铁／进入国家「十五五」”，暖金底、朱红强调、HOT标签，点击进入“一凡说高铁”。文案按用户提供的信息设置，本次未新增或伪造官方批复原文。已有专题继续分别展示资讯来源、个人解读及规划阶段说明。

- 电脑右下角显示；手机避开底部导航和安全区。
- 关闭或进入专题后，本设备24小时内不再展示；禁用存储时仍可在当前访问中关闭。
- 其他模块、登录表单和高度不足480px的横屏窗口不展示。
- 支持键盘焦点、明确关闭名称和系统减少动画偏好。

## 运营与交付边界

指南需运营人员录入真实来源、适用条件和实际核验日期，不预置未经核实的办事政策。岗位、服务名片为会员自填信息，内容审核不表示企业或专业资质认证。天气仅在活动配置坐标且日期在预报范围内显示，缺少条件时明确提示。

通知仅站内可读；本版不含微信订阅消息、短信或离线推送。资金众筹只记录意向；自提交付不自动改变线下结算状态。二维码不是支付码。

小程序完成编译，尚需微信开发者工具及真机验收；安卓、苹果实体设备的摄像头、系统相册、扫码和软键盘仍需真机测试。库存、预约和帮办并发使用单实例事务锁，当前按单实例试点运行。
