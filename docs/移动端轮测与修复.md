# 移动端轮测与逐项修复

更新：2026-10-28。依次从产品流程、前端体验和功能测试角度检查。交付形态为 Android / iPhone H5＋微信小程序。

| 编号 | 轮次 | 问题与影响 | 修复与结果 |
| --- | --- | --- | --- |
| P01 | 产品 | 权限不足以区分平台治理与板块管理 | 超管、普通管理员、组织者、分板块版主；后端权限测试通过 |
| P02 | 产品 | 商品销售需明确确认与收款边界 | 在线下单、人工确认、线下结算及履约状态；浏览器验证至手机收货 |
| P03 | 产品 | 外部照片来源403，无法导入 | 保留来源入口、提供本地相册上传；原照片仍待可访问素材 |
| F01 | 前端 | 新超管不命中旧管理入口 | 修正角色判断与标签，提供版主管理；双端检查通过 |
| F02 | 前端 | 小程序模板uni引用和事件类型不兼容 | 封装脚本函数；类型检查和mp-weixin编译通过 |
| F03 | 前端 | 聊天滚动区内边距裁切头像 | 调整box-sizing、宽度和头部布局；H5截图复核通过 |
| F04 | 前端 | 文字、快捷入口和触控尺寸偏小 | 手机正文15px、输入16px、快捷入口两列；按钮至少44px，20组矩阵通过 |
| F05 | 前端 | H5将扫码input/video变成uni组件，文件选择和摄像头引用失效 | render函数生成原生HTML控件；PNG识码、拒绝提示及模拟签到通过；卸载中停止摄像头启动 |
| F06 | 前端 | 退出或切账号后旧请求回写私人状态 | 共享请求作用域、同步身份监听、选择对象核验；5个延迟响应场景通过 |
| F07 | 前端 | 上传中切换相册／商品／会话可能写错目标 | 固定目标并检查有效性；聊天在选择文件后再次核验，附件卸载回收临时URL |
| F08 | 前端 | 360px底部导航不足44px，平板导航43px | 固定CSS像素最低高度；Web与H5五种尺寸复测通过 |
| T01 | 测试 | 私聊附件链接可能被非成员读取 | 每次校验成员及撤回状态；非成员、管理员越权及撤回后下载测试通过 |
| T02 | 测试 | Nginx旧64KB限制阻挡附件 | 上传路径单独16MB；配置审查完成，目标服务器验收待做 |
| T03 | 测试 | 隐藏／删除原帖后转发或引用泄露正文 | 动态校验来源状态，删除清空正文；后端回归通过 |
| T04 | 测试 | 并发下单及重复取消有超卖／重复退库存风险 | 写锁、幂等、状态校验；并发库存、取消、结算及revision测试通过 |
| T05 | 测试 | 移出源板块后仍可从转发读取原文 | 转发视图校验源板块canRead；新增回归通过 |

最终验证：50项后端测试、5个共享异步场景、两套类型检查、三端构建通过。浏览器流程与分段补验情况见[验收记录](验收记录.md)。

尺寸为360×800、390×844、412×915、844×390、768×1024，Web / H5首页与聊天共20组。无页面横向溢出，所查按钮高度≥44px；不代表所有链接或文本控件的完整无障碍审计。物理设备、软键盘、微信权限和前后台行为仍需真机验收。

语音追加：上传时锁定用户和编辑目标；微信临时文件名通过原文件名传给后端并重新验证格式；播放器在页面离开时停止并回收临时URL。3项后端语音权限回归、Web/H5实际上传播放通过，详见[语音使用说明](论坛语音.md)。
