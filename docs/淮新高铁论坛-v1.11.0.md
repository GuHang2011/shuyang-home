# 淮新高铁论坛 · v1.11.0

更新时间：2026-11-10。保留“一凡说高铁”名称和HOT标记，默认进入“淮新高铁讨论区”。首页增加“高铁论坛”直达入口，普通乡情论坛仍可从更多服务进入。

## 功能与使用

| 栏目 | 内容 |
| --- | --- |
| 高铁讨论 | 进展讨论、站点与接驳、返乡出行、资料分享、提问求证；关键词、热帖、最新／最多回复／待回复筛选 |
| 资讯与解读 | 保留专题资讯和一凡解读，展示来源、日期及原文链接；Web管理人员可发布、编辑 |
| 资料与常识 | 阅读文件的步骤、规划／审批／建设／运营的区别、常见问题、官方入口与关注区域 |

会员从“发起话题”选择讨论类型，填写标题与内容，可添加照片、语音。引用外部材料时可补充来源名称与原文链接，两项必须同时填写。来源由发帖者提供，填写链接本身不代表平台已核实其中的主张。提问、出行经验等原创内容不强制提供来源。

新帖和回复审核后公开。讨论沿用既有楼层、引用回复、转发、置顶和热帖功能；授权人员可审核、隐藏、关闭回复、禁言、移出及恢复。切换专题内部栏目保留当前发帖草稿，同时暂停语音，返回不自动播放；未完成的语音加载会作废。离开页面或刷新不提供草稿永久保存。

Web与H5可打开原文；微信小程序提供复制链接，受小程序平台规则限制，不在页面内打开任意外部网站。

## 权限与兼容

- 新板块为“淮新高铁”。专题内的公开帖子、我的帖子、审核和限制列表固定在该板块，不混入普通乡情帖子；提交时再次校验板块。
- 超级管理员、普通管理员和符合原权限规则的组织者沿用原有管理范围。论坛版主需明确获得“淮新高铁”板块授权，升级不会自动扩大已有版主权限。
- 服务端校验讨论类型及来源字段，拒绝非HTTP(S)链接、凭据型网址和非法字符。隐藏、删除及转发继续遵守原文可见性规则。
- 论坛数据仍存于已有JSON记录表，无需新增数据库表或迁移普通帖子。演示升级幂等补充三个明确标注的样例，保留当前浏览器已有记录。
