# 照片上传与界面优化

更新：2026-10-30。

## 使用照片功能

- **论坛**：审核通过的会员进入“老乡论坛 → 发起话题”，或打开一个可回复的话题，选择“添加照片”。一次最多 9 张 JPG / PNG，每张最多 8MB。发帖仍需填写标题；附照片或语音时正文可以留空。
- **选择与提交**：支持从相册或电脑选择多张图片，也提供手机拍照入口。选择后显示缩略图、上传进度和状态，可移除、重新选择；失败的照片保留，并提供重试。失败或仍在上传时，提交按钮不可用；全部完成或移除失败项后即可提交。
- **查看**：提交前的照片尚未公开，帖子与回复审核通过后展示。点击已发布的缩略图可查看大图，Web 支持 Escape 关闭预览；手机支持原生图片预览。
- **活动相册**：管理员和志愿组织者可在 Web、H5、微信小程序中建相册、选择照片、添加到相册、隐藏或恢复照片。草稿相册不公开。普通会员可以从相册页面进入论坛分享照片。
- **格式**：暂不接收 HEIC、GIF、SVG；HEIC 请导出为 JPG。服务器会实际解码图片、限制为 2000 万像素以内，并重新编码以去除原文件中的附加信息。

## 已修复的问题

| 问题 | 修改 |
| --- | --- |
| 正文和说明过小、颜色过淡，中英文字体混杂 | 统一中文界面字体；正文 15～16px，常用说明 13～14px；加深文字颜色，输入框为 16px |
| 手机按钮拥挤、表单不易点选 | 主要按钮至少 44px 高，操作行换行；优化表单间距与弹窗关闭按钮 |
| 论坛等内嵌表单使用浏览器默认样式 | 为标签、标题框、板块选择与正文输入补齐纵向布局、全宽控件、边框和聚焦反馈；聊天输入区保留独立布局 |
| 论坛只能上传语音 | 话题、回复支持多照片，并接入现有审核、拉黑、板块限制、隐藏与删除规则 |
| 上传失败缺少清晰反馈 | 逐张显示状态，支持重试与移除；取消选择不会显示失败提示；超量选择明确提示 |
| H5／小程序相册只有浏览入口 | 增加管理人员建相册、拍照、选择照片、提交与隐藏／恢复入口 |
| 论坛和相册标题重复占用首屏 | 删除重复标题，详情页优先展示内容 |
| 网页刷新或前进后退丢失栏目 | 栏目写入地址栏，支持前进、后退、刷新恢复；帖子内详情仍由“返回话题列表”操作 |

- H5 浏览器：查看 Web 发布的照片、上传图片回复、保存后再次读取、管理员建相册与上传照片通过。
- Web、uni-app 类型检查和 Web / H5 / mp-weixin 构建通过。
- 390px Web 发帖表单的标题、板块、正文控件均为316px宽、16px字号；通过浏览器字体检查确认中文正文实际使用 Microsoft YaHei。
