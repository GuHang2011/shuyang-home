# v1.8.0 换肤、拍照与在线演示

## 使用入口

- Web 顶栏、H5／小程序页面顶部的“换肤”：经典、竹青、暖金、夜间、跟随系统。选择保存在本机；跟随系统会随系统明暗设置变化，手动选择优先。
- 论坛发帖／回复、活动相册、聊天增加真正的摄像头拍照；Web 商品管理也可拍摄商品照片。
- Web／H5 拍照流程：实时取景 → 拍照 → 预览 → 重拍或确认。确认后上传，帖子仍需提交审核，聊天仍需点击发送，相册仍需点击添加，商品仍需保存。
- 浏览器照片压缩为最长边不超过1600像素的 JPEG；预览时即关闭摄像头。关闭、Escape、切后台、离开组件和身份／会话变更都会释放设备或丢弃迟到结果。

## 在线体验

入口：[沭阳之家在线体验](https://guhang2011.github.io/shuyang-home/)。顶部可直接切换演示会员、管理员和游客，无需填写真实资料。

演示账号为 `demo`、`admin`，密码均为 `Demo12345678`。这些字符串仅用于浏览器演示，不是后端管理员凭据。演示界面提供体验指引和重置按钮。

可体验主题、会员资料与审核、活动报名／取消、互助发布／审核、论坛图片与审核、聊天文字／表情／拍照、相册、商品／订单及文字／音频广播的主要操作。数据与附件保存在访问者自己的浏览器 IndexedDB；不同浏览器不共享。重置删除本机演示记录及附件，保留外观选择。演示附件总量限制50MB。

这是独立模拟环境，不提供跨设备聊天、真实交易或联机业务数据。扩展业务、真实文件报表、地点签到以及正式后端权限、并发和审计规则应在完整部署环境中验证；未覆盖的演示操作明确提示，不返回虚假的成功结果。

## 本轮发现与修复

| 问题 | 修复 |
| --- | --- |
| H5 构建成功，但相机异步模块路径不合法，点击后加载失败 | 移动端源目录内增加相机入口，保留共享实现和按需加载；用生产包验证真实浏览器流程 |
| 已完成拍照在账号切换后迟到，可能交给新账号 | await 后复核取消状态并释放图片 URL；新增竞态回归 |
| 夜间表格链接、相册、聊天和首页部分文字对比度不足 | 分离实心／文字按钮颜色，补齐主题表面和文字；复核桌面与手机截图 |
| 浏览器标签选择器进入小程序样式 | 分离浏览器主题选择器，只在 Web／H5 引入 |
| GitHub Pages 位于仓库子路径，原有根路径接口及图片不可直接访问 | 演示构建使用自身作用域的 Service Worker，本地处理接口并解析静态资源；正式构建不包含模拟接口 |
| 演示刷新丢失记录、不同访客可能共享数据 | 使用浏览器独立存储，串行提交并在存储成功后更新状态；验证刷新、隔离和重置 |

## 构建与维护

```powershell
npm --prefix frontend run typecheck
npm --prefix frontend run test:regression
node scripts/test-demo-runtime.mjs
npm --prefix frontend run build
npm --prefix frontend run build:demo
node scripts/test-demo-browser.cjs
python scripts/version.py check
```

`build`输出正式Web到`frontend/dist`；`build:demo`输出独立体验版到`frontend/dist-demo`。二者不要混用。浏览器脚本默认使用前端已安装的Playwright，可通过`SHUYANG_PLAYWRIGHT_MODULE`指定已有模块绝对路径；需要可用Chromium。它自动启动仅绑定127.0.0.1的静态服务器，并在退出时关闭，不需要后端。

`.github/workflows/pages-demo.yml`在main更新时校验版本、测试演示数据层、构建并部署Pages；不携带服务器凭据。Pages部署成功后，应再次打开公开链接核对实际版本和启动情况。源码／标签发布不等于完整业务服务器或微信小程序已上线。
