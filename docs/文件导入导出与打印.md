# 文件导入、导出与打印

从 v1.5.0 起，电脑网页在“管理工作台 → 数据管理 → 文件与打印”提供文件中心；手机 H5 和小程序在“我的 → 文件与打印”进入。普通管理员与超级管理员可以管理全部三类数据，组织者仅能操作活动报名，普通会员没有入口与接口权限。

## 支持的业务范围

| 类型 | 导入内容 | 保留的业务规则 |
| --- | --- | --- |
| 会员资料 | 按会员编号更新已存在普通会员的姓名、家乡、现居地、行业、个人简介 | 不创建账号，不修改手机号、密码、权限、审核状态或公开偏好；可选字段留空会清空该字段 |
| 活动报名 | 先选择活动，再按会员编号填写“报名”或“取消报名” | 检查会员审核与启用状态、活动状态、开始时间、容量及签到状态；同批取消可以释放名额 |
| 订单履约 | 按订单号填写“发货”或“备妥自提”，并填写 5–300 字说明 | 仅处理已确认订单，配送方式必须匹配；不创建订单、不修改付款、价格或库存 |

导出报表包含管理用只读信息，因此**导入须使用本页面下载的专用模板**，不能直接将报表原样上传。会员编号、订单号等必须保留完整，模板已将单元格设为文本格式。

## 导入流程

1. 选择业务类型；活动报名还须明确选择活动。
2. 下载导入模板，在 Excel 中填写。仅支持 `.xlsx`、一个工作表、文本单元格；最多 500 行数据、2 MB。
3. 选择文件并预览，查看每一行的记录、变化与错误。预览不会写入业务数据。
4. 有错误时修正文件并重新选择；所有行通过后，核对参与意愿或资料修改授权，勾选确认并提交。

系统拒绝公式、宏、外部链接、嵌入对象、错误表头、重复编号和过量解压数据。任何一行失败，整批都不写入。新预览会替换原待确认预览，有效期为 10 分钟；确认时再次核对业务状态及数据指纹，期间数据发生变化须重新预览。

网络中断时可在原预览重试，沿用同一个批次编号；服务端保证已提交批次不会再次更新。已提交摘要保留 24 小时用于重试，原始上传文件不会保存。成功导入后可在操作日志查看管理记录。

## 导出与打印

- 可以按关键词、业务状态筛选。修改筛选后须查询，避免导出旧结果。
- 屏幕每页显示 20 条；Excel 与打印包含当前筛选的**全部记录**，不受屏幕分页影响。单次最多 5,000 条，超过后要求缩小筛选范围。
- 编号、手机号和可能以公式字符开头的文本均按文本单元格输出；时间标明北京时间。
- Web 与 H5 通过浏览器打印界面选择打印机或“保存为 PDF”。报表使用 A4 横向、重复表头，去除导航与操作按钮，字段均经过 HTML 转义。
- 微信小程序选择聊天中的文件导入；导出后通过文档预览菜单保存或分享。“导出供打印”生成 Excel 文件，再交由支持打印的设备操作；小程序没有直接调用系统打印机的能力。

## 界面与兼容性

Web 使用 Vue 3 对应的 Element Plus 2.14.7，文件类型、筛选、表格、分页、上传、确认及结果提示均采用真实组件。uni-app H5／小程序保留原生兼容控件，共享业务逻辑与 API。

验收使用独立内存数据库与合成会员、活动、订单，覆盖错误行、预览不写入、整批提交、网络重试、分页导出与完整打印。复现脚本、双浏览器结果与界面说明见[Element 界面与验收](Element界面与验收.md)和[测试脚本说明](../scripts/README.md)。物理打印机、微信小程序真机与手机系统软键盘须在实际设备上进一步验收。
