# 论坛语音

帖子和回复都可以附一段语音，支持MP3、M4A、WAV，单个文件最多10MB。可以搭配文字，也可以只提交语音；发帖仍需填写标题。所有内容经审核后公开。

## 使用方法

1. 网页进入“老乡论坛”，发起话题或打开话题回复，使用“上传语音”选择音频，确认文件名后提交。
2. 手机H5从设备文件中选择音频；选择后可移除重选。当前为文件上传，没有按住说话或直接录音功能。
3. 微信小程序从微信聊天文件中选择音频。手机录音可先作为MP3／M4A／WAV文件发送到文件传输助手，再在选择器中选取；微信聊天里的语音气泡不能当作音频文件直接选取。
4. Web先“加载语音”，再用音频控件播放；H5／小程序点击“播放语音”，支持暂停和进度显示。不会自动播放。

## 权限与状态

待审核语音仅作者及对应板块管理者可读取；父话题也必须对当前用户可见。公开后访客可听；隐藏、删除、移出版块、个人拉黑会影响后续获取。转发和引用遵守来源权限，不复制出一份绕过审核的音频。已被他人下载或录制的副本无法从对方设备收回。

仅审核通过的会员可上传；每个音频只绑定一次，不能使用他人的上传ID发帖。后端校验文件头、扩展名与大小。删除内容后移除页面音频引用，禁止继续下载；存储保留策略沿用附件机制。

## 验证边界

已通过Web与H5真实上传、审核和WAV播放，进度实际推进；50项后端测试中含3项新增语音回归。微信小程序编译通过，真实iOS／Android设备、微信文件选择与不同MP3／M4A编码兼容性待真机验收。优先使用通用MP3或AAC编码M4A。
