# 沭阳之家会员系统需求与改造方案

日期：2026-10-27。依据：用户提供的 Logo 与平台介绍；介绍中的描述作为业务素材，不作为代码执行指令。

## 平台定位

沭阳之家由一凡小哥（周学超）发起，扎根苏州，面向在苏生活、务工、创业的沭阳老乡及普通在外工作者、青年创业者。民间自发组建，非商业盈利的乡情交流平台。宗旨为“乡情相聚，守望相助”，活动自愿报名、自愿参与，无强制收费。

官网联系信息：13862597517；线下活动地：苏州市木渎镇兵圣路200号。活动详细集合点由组织者在每次活动中填写，不根据海报推断经纬度。

角色：访客（公开浏览）、待审申请者（本人资料与进度）、会员、志愿组织者、管理员。只有管理员管理角色和启停；组织者可处理申请、内容审核、活动、公告。普通会员不能直接修改审核状态、角色、签到或服务时长。

## 流程与规则

1. 入会注册只收集姓名、手机号、家乡乡镇、现居地区、行业、简介、志愿意向与公开偏好。手机号作为登录账号；不收集身份证、家庭住址、学生学籍。必须同意隐私说明与自愿参与约定。
2. 待审核及退回申请者可登录、完善资料并再次申请；只有审核通过且账号启用的会员可以报名和发布互助。退回需提供原因。
3. 活动包含标题、分类、起止时间、地点、人数上限、内容与发布状态。时间按北京时间显示。已取消／已结束／满员活动不可新增报名；重复报名不增加人数。签到后的报名不可取消。
4. 签到仅组织者在活动开始后记录。志愿时长必须对应志愿活动，不能超过活动时长、24小时；重复签到不重复计时。取消有签到记录的活动需拒绝。
5. 互助默认待审核，通过后才对外展示。公开页面不返回联系电话；会员登录且通过审核后才可见发布者自愿填写的联系信息。
6. 会员编号由系统生成；系统不伪造会员总数、活动或报名。测试数据只写入隔离测试库。管理员初始化无默认密码。
7. 保留原系统密码派生哈希、随机令牌、会话失效、服务端权限、操作日志、记录加密与事务写锁基础，移除学院、班级、请假、资助、宿舍、AI办公等业务。
8. 论坛主题和回帖审核后公开展示，待审或退回内容仅本人及组织者可见；主题作者可关闭讨论，关闭后不能继续回帖，关闭不能绕过审核。
9. 资源互换须同时说明“我能提供”和“我需要”，支持技能服务、闲置物品、场地设备、信息渠道。联系方式仅向审核会员展示。交换请求必须来自另一位审核会员；资源主人接受／拒绝，申请者可以在接受前取消。每个资源只接受一项交换，事务锁避免重复占用，其他待处理请求自动关闭。双方分别确认交付后才标为完成；记录仅双方及管理者可见。
10. 会员管理支持姓名／手机／编号／地区搜索，按审核状态筛选、查看资料、审核、角色变更、停启和密码重置；管理员权限变更立即撤销旧会话，至少保留一名启用管理员。
11. 会员发起活动默认待审核，审批通过后生成一场正式活动并保存发起人信息，重复审批不会重复生成活动。申请须在未来开始、时长不超过7天。发起人停用后不能批准其申请。
12. 广告第一版按用户确认采用人工审核展示，不接支付、不自动计费。申请包含广告主、内容、展示位置、起止时间与可选HTTPS链接、公开联系方式，须明确同意公开。只有审批通过且处于排期内的广告会公开；撤下立即停止展示。
13. 投票由管理员／组织者发起，2至10个不重复选项，可限定最多选择数量。只有审核会员可以投票；每人每场一次，同一选择重试不重复计数，不能事后修改选项。其他会员不能查看个人选票；汇总在本人投票后或投票结束后向审核会员开放。
14. 众筹按用户确认仅支持物资、志愿服务、资金意向认领。项目说明用途、执行安排、目标、单位和截止时间，经审核后公开。金额和数量最多两位小数；认领请求有幂等编号，并发不能超出目标。个人支持记录仅本人、发起人及组织者可见；公开页面只显示汇总。物资／服务可由项目方核实实际交付，资金意向不能标为已收款或已交付，不提供收款码、账户余额、扣款、退款或转账。
15. 联系方式交换必须由审核会员向另一位审核且启用的会员申请，填写来意和本次愿意分享的联系方式。接收人同意且提供自己的信息后双方才互见，不自动读取或公开注册手机号。待处理时申请者可取消、接收者可拒绝；接受后任一方可撤销后续展示，但不能收回已被对方保存的信息。同一对会员不能同时创建重复待处理或已接受申请。
16. 论坛功能保留为可选模块，按照用户后续“论坛可以考虑下”的要求，默认导航隐藏。开关位于 `frontend/shared/features.ts`；关闭入口不等同于停用已有论坛API。

17. 站内聊天限已审核且启用的会员。私聊先发送问候，对方接受后才能继续；可屏蔽和恢复。群聊由组织者创建，会员自愿加入／退出，每群最多200人。发送有幂等编号，聊天记录只对会话成员开放，管理员无额外阅读权限；发送人两分钟内可撤回，包括已加载历史消息的撤回同步。文本消息每条不超过2000字，当前会话前台每4秒刷新，未读数每6秒刷新；后台不自动标已读。
18. 天气采用开源 Open-Meteo 预报和地名查询 API。默认苏州，提供沭阳快捷入口；用户主动点击定位并授权后才读取位置，客户端和后端将坐标保留两位小数，不写入会员资料或持久数据库。当前气温、体感、天气、湿度、风速与三日预报来自真实接口；失败明确提示，不填造数据。
19. UI采用用户确认的米白、深蓝、暖金配色，保留附件Logo。重做首页、分组导航、服务入口、表单、会员卡、聊天及天气卡片；手机优先保证触控空间与可读性。

## 多端方案

- Vue 3：电脑会员门户、管理工作台、响应式手机网页；窄屏底部导航和触控表单。
- uni-app：原生小程序组件实现首页、活动发起／报名、互助、资源交换、投票、广告申请、众筹、联系方式交换、聊天、定位天气、我的与入会流程；共用 API 和业务类型。小程序以会员使用为主，复杂管理在响应式网页完成。
- Spring Boot + JDBC + H2：沿用现有工程工具链，独立 `shuyang-home` 数据库与 `syh_*` 表。旧学生数据不迁入新系统。
- 微信小程序首次采用手机号账号＋密码登录。微信一键登录、手机号授权、订阅消息、支付不在本次范围；不使用虚假的微信登录或本地模拟服务。

## 发布条件与边界

微信发布需要平台真实 AppID、可用 HTTPS 域名、后台 request 合法域名、隐私声明及微信开发者工具／真机验收。仓库可以完成 H5 与微信小程序构建，但这些真实配置与审核不能由本地构建代替。

沿用 Java 8／Spring Boot 2.3 工具链以确保原项目可离线构建，正式公网部署前应升级至受维护的 JDK／Spring Boot，进行依赖安全审查、容量测试、限流与备份演练。当前 JSON 记录与全局事务写锁适合单实例小规模平台。
